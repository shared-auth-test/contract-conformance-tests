shared-auth

One identity across every OreSoftware app — running in tandem with Supabase, never replacing it.

What it is

A centralized auth server that verifies Supabase access tokens from any of our orgs, mirrors identities into one namespace (shared_user_id), and mints a single ES256 JWT every service trusts via one JWKS.

The dual-auth race

Every guard races shared-auth against Supabase built-in auth concurrently and takes the first success — so either authority alone carries a multi-minute outage of the other, and "could not decide" is never rendered as "logged out".
